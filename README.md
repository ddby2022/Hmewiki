# DBY 的手账

一个暖色手账风的单页个人网站，by GPT 6.1 So1 and Deepseek 4.1 flash

## 文件结构

```text
mesite/
├─ index.html          # 页面结构、文案、推荐卡片
├─ styles.css          # 手账风视觉、布局、响应式、动效
├─ script.js           # 导航、日期、弹窗、复制链接、滚动入场
├─ assets/
│  ├─ avatar.svg       # 手绘头像
│  └─ favicon.svg      # 站点图标
└─ README.md
```
