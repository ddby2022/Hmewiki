# DBY 的手账

一个暖色手账风的单页个人网站，核心包含「介绍自己」与「推荐阅读 / 推荐收听」两个模块。

- 纯 `HTML + CSS + JS`，无框架、无构建步骤、无外部依赖
- 桌面双栏推荐、移动端单栏堆叠
- 移动端（≤860px）隐藏头像照片，只保留座右铭便签
- 推荐卡片可键盘操作，点击打开完整推荐语弹窗
- 支持 `prefers-reduced-motion`，包含键盘焦点样式与图片替代文本

## 如何预览

直接双击 `index.html` 用浏览器打开即可。

如果希望用本地服务器预览：

```powershell
# 在 E:\mesite 目录下
npx serve .
```

## 文件结构

```text
mesite/
├─ index.html          # 页面结构、文案、推荐卡片
├─ styles.css          # 手账风视觉、布局、响应式、动效
├─ script.js           # 导航、日期、弹窗、复制链接、滚动入场
├─ assets/
│  ├─ avatar.svg       # 手绘头像
│  └─ favicon.svg      # 站点图标
└─ README.md
```

## 换成你自己的内容

- **姓名 / 简介 / 关键词 / 座右铭**：修改 `index.html` 中 `.hero-copy` 与 `.motto-card` 内的文案。
- **头像**：用自己的正方形或 6:7 图片替换 `assets/avatar.svg`，并把 `index.html` 中 `img` 的 `src` 和 `alt` 改掉。
- **GitHub / 联系方式**：搜索 `https://github.com/ddby2022`，替换为你的链接。
- **推荐阅读 / 收听**：
  - 卡片上的标题、短评、封面字在 `index.html` 的 `.rec-card` 中；
  - 点开后的完整推荐语在 `script.js` 的 `recommendations` 对象中；
  - 两处都改，预览与弹窗才会一致。
- **日期**：页头的月 / 日与星期、页脚年份由 JS 自动生成；`EST. 2026` 与 `OCT. 2026` 是手账标记，可以直接改。

## 设计说明

- 配色：奶油纸 `#f4ead9`、暖砖红 `#a34a2b`、芥末黄 `#d4a141`、鼠尾草绿 `#77886c`
- 字体：中文标题用系统楷体，正文用系统无衬线字体，英文标记用等宽字体；不依赖网络字体
- 装饰：胶带、拍立得、圆形手账章、便签、打孔活页线、纸张颗粒
- 无障碍：语义化标题层级、跳转正文链接、弹窗焦点管理、Esc 关闭、键盘可操作卡片、降低动态效果偏好支持

推荐内容为示例内容，可以按自己的阅读与收听口味自由替换。
